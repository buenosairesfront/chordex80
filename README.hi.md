# Chordex 80

[monome norns](https://monome.org/docs/norns/) के लिए 80 के दशक के पॉलीसिंथ वाला कॉर्ड वाद्य। एक बटन एक कॉर्ड बजाता है (दबाया गया सबसे नीचा बटन मूल स्वर तय करता है), एक पॉलीफ़ोनिक इंजन के ज़रिए जिसमें उस दशक की क्लासिक मशीनों से प्रेरित तीन मॉडल हैं, और स्क्रीन पर एक outrun शैली का सूर्यास्त बनता है।

![Chordex 80](docs/sheet.png)

**दृश्य ही सिंथेसाइज़र है:**

- **सूरज:** उसका आकार फ़िल्टर है (E1), प्रभामंडल रेज़ोनेंस है, धारियाँ डिस्टॉर्शन हैं, काँपना wobble है, दोनों ओर की परछाइयाँ कोरस (fatness) हैं, और उसकी चमक वह एनवेलप है जो आपके बजाने के साथ साँस लेता है
- **तारे** shimmer हैं, **चिंगारियाँ** चटकन हैं (दो से ज़्यादा बटन दबाने पर)
- **ग्रिड** आर्पेजियो की गति से आगे बढ़ता है; हर नोट सड़क पर एक रोशनी है

## विशेषताएँ

- **3 मॉडल**: D-50, CS80 और OMNI (Roland D-50, Yamaha CS-80 और ARP Omni से प्रेरित), D-50 के लिए अटैक चुनने का विकल्प (हवा, pluck, कोई नहीं)
- **10 कॉर्ड**: maj, min, dim, aug, 7, maj7, min7, m7b5, sus2, sus4
- **आर्पेजिएटर**: up, down, up-down, up x2, down x2, random और *arpa* (हार्प); गेट बहुत छोटे से लेकर असली लेगाटो तक (एक आवाज़ जो कभी नहीं कटती)
- **कॉर्ड मोड** चालू/बंद (बंद = एक नोट) और **होल्ड**
- आने वाली MIDI क्लॉक सिर्फ़ आर्पेजियो की गति तय करती है, कभी नोट नहीं बजाती; ताल पर एक ही नोट दोहराने से कॉर्ड दोबारा ट्रिगर नहीं होता
- बाहर निकलते समय सब कुछ सेव होता है और लोड करने पर वैसा ही लौट आता है

## कंट्रोल

| कंट्रोल | काम |
|---|---|
| E1 | फ़िल्टर |
| E2 | पैरामीटर चुनें |
| E3 | पैरामीटर समायोजित करें |
| K3 + E1 | मॉडल: D-50 / CS80 / OMNI |
| K3 + E2 | रेज़ोनेंस |
| K3 + E3 | कॉर्ड का प्रकार |
| K3 दबाए रखें (बिना घुमाए) | कॉर्ड मोड चालू/बंद |
| K2 (टैप) | आर्पेजिएटर चालू/बंद |
| K2 + E1 | आर्पेजियो गेट (अधिकतम = लेगाटो) |
| K2 + E2 | आर्पेजियो पैटर्न |
| K2 + E3 | आर्पेजियो गति |
| K1 दबाए रखें | होल्ड चालू/बंद (फ़ेडरों के बाईं ओर भरा बिंदु = होल्ड) |

**फ़ेडर:** अटैक, डिके, डिस्टॉर्शन, shimmer, wobble, fatness।

**PARAMETERS मेनू:** MIDI चैनल (डिफ़ॉल्ट 1; 0 = सभी), MIDI क्लॉक डिवाइडर, D-50 अटैक, हॉल, वॉल्यूम, और ऊपर का सब कुछ।

## arc और crow

दोनों वैकल्पिक हैं: arc या crow जुड़ा न हो तो कुछ नहीं बदलता।

**arc** (4 रिंग, नॉब की तरह दिखते हैं): 1 फ़िल्टर · 2 रेज़ोनेंस · 3 आर्पेजियो की गति · 4 हॉल

**crow**: IN1 = सुर (V/oct, 0 V = C4), IN2 = गेट (बजाना और छोड़ना) · OUT1 = कॉर्ड का मूल सुर (V/oct) · OUT2 = एनवेलप (0–8 V, ध्वनि के अटैक और रिलीज़ के साथ) · OUT3 = टेम्पो वाला LFO (1 बार) · OUT4 = हर कॉर्ड या आर्पेजियो स्टेप पर एक पल्स। PARAMETERS > ARC / CROW में बंद किया जा सकता है।

**टेम्पो:** पहली बार चलाने पर आंतरिक टेम्पो 50 BPM होता है। आने वाली MIDI क्लॉक (किसी भी MIDI पोर्ट पर) मौजूद हो तो वही टेम्पो तय करती है।
